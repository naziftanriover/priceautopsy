Privacy Policy

Last updated: November 22, 2026

This policy covers "Price Autopsy Uploader", a private tool used solely by the owner of the Price Autopsy YouTube channel to upload and manage that channel's own videos.

What data the tool accesses

With the channel owner's permission (Google OAuth), the tool uses the YouTube Data API to upload videos, set thumbnails and update video and channel details for the owner's own channel. It does not access any other user's data.

How data is stored

The OAuth token is stored only on the channel owner's own computer. No data is sold, shared with third parties, or used for advertising. The tool performs no analytics or tracking.

Google API Services

The tool's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Access can be revoked at any time at myaccount.google.com/permissions.

Viewers

Watching Price Autopsy videos on YouTube is governed by Google's Privacy Policy. This website sets no cookies.
